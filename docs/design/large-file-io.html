File I/O & Index

SigMF/HDF5 大文件读取、预览索引与缓存

SigMF 数据文件与 HDF5 RFML 数据集可能从 MB 到 TB 不等，RFview 必须按样本窗口读取、渐进式计算，并把可视化与统计结果缓存为可复用索引。

读取原则

  • 根据 SigMF core:datatype 计算样本宽度，或根据 HDF5 dataset shape/dtype/chunk 计算 frame 与 hyperslab 范围。
  • 只读取当前视口、统计任务或导出任务所需范围，避免全文件载入内存。
  • 支持 chunk reader、mmap window、HDF5 hyperslab、异步 prefetch 和取消机制。
  • 所有读取任务必须附带 capture 或 dataset 上下文，正确解释采样率、中心频率、时间戳、frame index 和标签来源。

首屏策略

导入后优先读取文件开头、首个有标签片段或 RadioML 首个 frame，快速展示波形、PSD 与标签概览。

后台策略

空闲时构建预览金字塔和低分辨率瀑布 tile，再按用户浏览位置补齐高分辨率 tile。

一致性策略

保存 meta 后重新计算受影响范围，并在 UI 标记旧缓存已失效或正在刷新。
