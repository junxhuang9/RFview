SigMF Data Model

SigMF 到 RFML 资产模型的映射

把 SigMF 的 global、captures、annotations 和 extensions 转换为可检视、可统计、可标注、可导出的内部对象。

总览系统架构SigMF 数据模型数据集管理文件读取与索引统计工具可视化分析标签与元数据技术路线实施路线

内部对象

SigMF 概念RFview 对象用途
globalRecordingProfile保存 datatype、sample_rate、author、description、license、hw、recorder、sha512 等全局信息。
capturesCaptureSegment描述 sample_start、frequency、datetime、sample_rate 覆盖变化，驱动时间轴与频率轴换算。
annotationsLabelSegment描述 sample_start、sample_count、freq_lower_edge、freq_upper_edge、label、comment 和项目自定义标签。
extensionsExtensionNamespace登记自定义字段命名空间、schema URL、版本和 UI 表单定义。
collectionDatasetCollection组织多个 recording，形成 RFML 数据集、划分集合和质量门禁。

校验层级

  1. 结构校验：JSON 可解析、必需字段存在、datatype 合法、sample_start 单调、sample_count 不越界。
  2. 文件一致性：meta/data 成对、样本格式与文件大小匹配、hash 可选校验、collection 引用可解析。
  3. RF 语义校验：采样率、中心频率、频带边界、时间戳和多 capture 切换是否合理。
  4. RFML 规则：标签集合闭包、类别映射、最小片段长度、训练/验证/测试划分不泄漏。

RFML 派生字段

  • class_id：由 label taxonomy 映射得到。
  • split：train / val / test / holdout。
  • quality_score：由缺失字段、异常统计、人工复核状态汇总。
  • slice_policy：窗口长度、步长、重叠、是否按标签边界裁剪。

保留原则

  • 未知 SigMF 扩展字段必须保留，不能在保存时丢失。
  • 编辑器生成的字段使用明确 namespace，避免污染标准字段。
  • 导出 RFML 清单时只引用原始样本范围，不复制大文件。
