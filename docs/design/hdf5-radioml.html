HDF5 / RadioML2018

HDF5 文件格式支持与 RadioML2018 数据集兼容

在 SigMF 之外，RFview 需要能把 HDF5 封装的 RFML 数据集作为只读资产导入，并把 RadioML2018.01A 的 X/Y/Z 结构映射为可浏览、可统计、可导出的内部样本窗口。

总览 系统架构 SigMF 数据模型 数据集管理 文件读取与索引HDF5/RadioML 统计工具 可视化分析 标签与元数据 技术路线 实施路线 P0 校准

导入目标

HDF5 支持不替代 SigMF，而是增加一个 Dataset Adapter：扫描 .h5、.hdf5 文件，识别根目录数据集、shape、dtype、chunk 与属性，再把可解释的数据集投影成 RFview 的 Recording、LabelSegment 和 RFML manifest 行。原始 HDF5 文件默认只读，不复制、不重写。

RadioML2018.01A 兼容契约

HDF5 数据集预期结构RFview 映射
/X[frame, 1024, 2] 或等价的 I/Q 轴布局，float I/Q 分量。每个 frame 映射为一个 1024 点复数样本窗口，内部规范化为 cf32 视图。
/Y[frame, 24] one-hot 调制类别。one-hot 最大值索引映射到 modulation taxonomy，生成 label_id 与 label_name。
/Z[frame, 1] 或 [frame] SNR，常见范围为 -20 dB 到 30 dB、步进 2 dB。作为样本级 SNR 字段写入统计索引、筛选器和 RFML manifest。
/classes* 或伴随 classes-fixed.json/classes-fixed.txt调制类别顺序。优先读取伴随类别文件；缺失时使用内置 RadioML2018 类别顺序并标记警告。

导入流程

  1. 识别扩展名与 HDF5 magic，列出根节点和必要数据集。
  2. 校验 X、Y、Z 第一维 frame 数一致，检查 dtype、shape 和 chunk 信息。
  3. 读取或推断类别表，构建 modulation taxonomy，并记录类别来源。
  4. 为每个 frame 建立虚拟样本范围：sample_start = frame_index * frame_len，sample_count = frame_len。
  5. 只按用户视口读取 HDF5 hyperslab，避免一次性载入 21GB 级数据集。
  6. 生成目录索引、类别/SNR 分布、预览缓存和可导出的 RFML manifest。

质量门禁

  • 阻塞 缺少 X、Y 或 Z，或三者 frame 数不一致。
  • 阻塞 X 无法解释为 I/Q 双通道，或 frame 长度不是正整数。
  • 警告 类别表缺失、one-hot 多热/全零、SNR 为空或超出预期范围。
  • 警告 HDF5 未 chunk 化或 chunk 形状不利于随机 frame 读取。
  • 通过 X/Y/Z 结构一致、类别可解析、可按 frame 窗口读取 IQ。

内部对象映射

RFview 字段RadioML2018 来源说明
asset_idHDF5 文件路径、大小、mtime、hash。一个 HDF5 文件作为一个 DatasetAsset；frame 可作为虚拟 recording item。
source_urifile:///.../GOLD_XYZ_OSC.0001_1024.hdf5#Xmanifest 保留 HDF5 URI 与 dataset path，便于训练端延迟读取。
sample_rate/center_frequency_hzHDF5 attribute、sidecar manifest 或用户导入配置。RadioML2018 通常不提供真实采样上下文；缺失时显示为 unknown，不阻塞调制分类用途。
label_id/label_nameY one-hot + 类别表。生成 mod.ook、mod.qpsk 等稳定 taxonomy ID。
snr_dbZ。用于筛选、分组统计、train/val/test 分层抽样和异常报告。

RFML manifest 示例

{
  "asset_id": "rml2018_01a",
  "source_uri": "file:///data/GOLD_XYZ_OSC.0001_1024.hdf5#X",
  "format": "hdf5.radioml2018",
  "frame_index": 123456,
  "sample_start": 126418944,
  "sample_count": 1024,
  "sample_dtype": "cf32",
  "label_id": "mod.qpsk",
  "label_name": "QPSK",
  "snr_db": 10,
  "split": "train"
}

实现注意事项

  • 读取层使用 HDF5 hyperslab 或等价切片 API，支持按 frame 批量读取和取消。
  • 索引层缓存类别/SNR 分布即可；不要把全部 X 数据展开到 SQLite。
  • 可视化层复用现有 IQ/PSD/瀑布组件，但 frame 边界默认不可跨越，除非用户选择连续拼接模式。
  • 写回策略保持只读；用户标注或 split 变更保存为 workspace overlay 或伴随 manifest。
