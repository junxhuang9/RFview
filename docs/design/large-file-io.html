关键原则

  • 只读当前视口和邻近预取窗口，不将完整文件复制到应用内存。
  • 文件打开后先读取头部小窗口，立即生成“文件开始处”的抽样预览。
  • 后台构建多分辨率抽样金字塔，使任意跨度的时间轴都能快速显示概要。
  • 缓存与原始文件分离；缓存失效由文件路径、大小、mtime 和内容指纹共同判断。

读写策略

场景策略说明
打开文件读取元数据 + 头部样本窗口目标在 1 秒内展示起点附近的 IQ 和粗频谱。
视口跳转按样本范围换算字节范围并异步读取支持从时间、样本序号或字节偏移定位。
连续浏览环形缓冲 + 邻近窗口预取前后各预取若干窗口，滚动时复用缓存。
瀑布图缩放读取预计算 FFT tile，不足时即时计算优先显示低分辨率 tile，再逐步替换为高分辨率 tile。
插件解调流式块读取 + 背压插件处理速度慢时暂停上游读取，避免内存膨胀。

抽样预览方案

  1. 默认从文件开始处读取首个 preview window。
  2. 根据样本格式快速解交织 I/Q，并计算 min/max、RMS、功率谱概要。
  3. 生成多级 downsample：例如 1:1、1:64、1:4096、1:262144。
  4. UI 时间轴先展示最粗一级，再按当前缩放请求细粒度数据。

大文件安全边界

所有 API 均使用 64 位偏移和长度；任何读取请求都必须经过边界检查、样本格式校验和最大块大小限制。错误不应导致 UI 阻塞，而应以可恢复诊断呈现。
