computeDiff() 对原始备份和当前修改后的 JSON 逐行比较， 深色终端风格显示：绿色(+)新增、红色(-)删除、灰色(=)未变。 通过模态对话框展示，支持点击外部关闭。

P3 编辑器嵌入左侧元数据面板，Global 字段表格、Capture 表格和 Annotation 列表分区清晰。编辑浮窗定位在目标行旁，模态确认框居中。 所有样式与 P2 设计系统一致（CSS 变量、圆角、阴影）。

确认/取消按钮 5.2 防误操作设计

⚠️
XSS 安全审查 escHtml 使用完整性
escHtml() 函数已实现在行 2060-2063，用于防止 HTML 注入。 但 仅在行 1978（描述字段）调用了 escHtml()， 而行 1979-1981 的 author、 hw、license 字段 未使用 escHtml。
🔴 XSS 风险（中危）：虽然这些字段通常由技术用户编辑， 且行 1978-1981 的值被包裹在 value="${...}" 属性中， 但属性值未转义引号。如果作者/硬件/许可证字段包含 " 或 >， 可能导致 HTML 注入。建议统一使用 escHtml()。

🚀 改进建议

  • [安全] 统一 escHtml 调用 — 在行 1979-1981 对 author、hw、 license 使用 escHtml()。 建议在 renderEditableMetaPanel 中建立一个 safeAttr(value) 包装函数，确保所有属性输出都经过转义。
  • [安全] 改用事件委托 — KV 删除按钮改用 kvContainer.addEventListener('click', ...) 事件委托，避免内联 onclick 和全局导出依赖。
  • [功能] 保存后同步 originalMeta — 保存完整 meta 后 将 originalMeta = deepClone(currentMeta)， 使下次 diff 准确反映增量修改。
  • [UX] 可关闭的风险警告 — 为 #dtWarn 和 #srWarn 添加 ✕ 关闭按钮， 或将警告改为一次性提示（用户确认后不再显示）。
  • [代码] 消除 getModifiedMeta 副作用 — 分离"收集"和"更新"逻辑， 或重命名为 collectAndReturnModifiedMeta() 更准确表达。
  • [代码] 清理 undefined 赋值 — 行 2341-2342 删除 'core:freq_lower_edge': undefined， 在新标注中直接不设置该字段。
  • [代码] 提取模块 — 考虑将 P3 功能拆分为独立 JS 文件： metaEditor.js、annotManager.js、 saveManager.js，便于维护和测试。
  • [测试] 追加自动化测试 — 当前纯手工审计。建议使用 Puppeteer/Playwright 对编辑、保存、撤销流程做 E2E 测试。
