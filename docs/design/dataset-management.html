Dataset Management

SigMF 与 HDF5 数据集管理和质量门禁

面向 RFML 的数据集管理需要同时管理文件、元数据、标签、统计结果、派生切片和审计状态。

数据集工作区

  • 一个工作区可挂载多个本地目录、SigMF archive、collection 文件或 HDF5/RadioML2018 文件。
  • 扫描器为每个 recording 或 HDF5 dataset asset 建立唯一资产 ID，并记录路径、大小、mtime、hash、格式族、schema/shape 摘要和导入状态。
  • 索引数据库只保存目录与派生信息；原始 .sigmf-data 和 .hdf5 不复制、不改写。

管理视图

视图主要字段操作
Recording / Dataset 列表名称、格式、采样率、中心频率、样本数或 frame 数、时长、datatype/dtype、标签数、健康状态。打开、重新校验、生成预览、加入集合、导出报告。
Collection 视图集合名称、成员数量、类别分布、split 分布、覆盖频段、覆盖时间。划分 train/val/test、批量规则检查、导出 manifest。
质量问题面板问题等级、文件、样本范围、规则 ID、修复建议。定位、忽略、批量修复、生成待办。
派生资产视图预览 tile、统计快照、切片清单、人工标注版本。清理缓存、重新计算、比较版本。

检索与筛选

  • 按格式、频段、采样率、datatype/dtype、调制标签、SNR、时长、采集设备、采集日期筛选。
  • 支持保存查询，例如“所有 unlabeled 且 SNR < 5 dB 的片段”。
  • 支持全文搜索 comment、description、author 和自定义 namespace 字段。

RFML 导出

  • 导出 JSONL/CSV manifest：文件 URI、样本起止、标签、split、预处理参数。
  • 导出质量报告：标签覆盖、类别均衡、异常片段、未通过规则。
  • 导出切片计划：窗口长度、步长、是否跳过低质量片段。

质量门禁建议

进入训练前必须通过四类门禁：SigMF 合规、样本文件一致、标签完整、训练划分无泄漏。未通过门禁的数据仍可浏览，但导出 RFML manifest 时应明确标记或阻止。
