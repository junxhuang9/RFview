Plugin System

类似 VS Code 的信号解调插件体系

插件通过 manifest 声明能力，通过受控 API 读取样本、输出分析结果，并可贡献命令、设置项和自定义视图。

总览系统架构技术路径TB 级文件读写解调插件体系多域分析视图实施路线

插件能力

  • Demodulator：接收 IQ 样本块，输出符号、比特、帧、协议字段和置信度。
  • Analyzer：计算占用带宽、调制识别、突发检测、同步点和统计指标。
  • Format Provider：解析特定厂商或仪器的文件头、sidecar 元数据和样本编码。
  • View Provider：贡献结果表格、星座图、眼图、协议树或自定义图层。

Manifest 草案

{
  "id": "org.example.fsk-demod",
  "name": "FSK Demodulator",
  "version": "0.1.0",
  "engine": "rfview-plugin-api@1",
  "entry": "plugin.wasm",
  "capabilities": ["demodulator", "analyzer"],
  "sampleFormats": ["ci8", "ci16", "cf32"],
  "permissions": ["readSamples", "writeResults"],
  "contributes": {
    "commands": [{ "id": "fsk.start", "title": "Start FSK Demod" }],
    "settings": [{ "key": "symbolRate", "type": "number", "default": 9600 }]
  }
}

插件生命周期

  1. 发现：扫描用户插件目录和工作区推荐插件。
  2. 校验：验证 manifest、签名、API 版本和权限声明。
  3. 激活：按命令、文件格式或用户操作懒加载插件。
  4. 运行：通过消息通道收发样本块、参数和结果。
  5. 停止：支持取消任务、保存状态和释放资源。

安全与性能

  • 优先使用 WebAssembly 沙箱，限制文件系统、网络和内存配额。
  • 插件不可直接读取 TB 文件，只能请求核心引擎提供的受控样本流。
  • 结果输出采用结构化 schema，便于缓存、查询、可视化和导出。
  • 长时间插件任务必须周期性上报进度，并响应取消信号。
