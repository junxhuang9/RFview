📊 视图矩阵测试 5/5

✅
IQ 时域图 plotIQ() — ~60 行
scattergl 模式高性能渲染 I/Q 双线(蓝/红)， 时间轴单位秒，capture 段绿色虚线标记， hover 信息包含 I/Q 名称和数值。
📌 循环生成时间数组 Float64Array(N) → Array.from(t)， 大数据窗口下可能有内存开销，但 scattergl 有效缓解。
✅
星座图 (Constellation) plotConstellation() — 新增 ~80 行
scattergl 散点图 I vs Q，半透明着色 rgba(30,102,245,0.5)，>20000 点自动降采样， 单位圆虚线参考线，I/Q 轴等比例 scaleanchor:'y' + scaleratio:1， 自动计算显示范围 maxAmp * 1.3。
✅
PSD 频谱图 plotPSD() + welchPSD() — ~80 行
自实现 Welch 法（Hanning 窗，50% 重叠，FFT=1024）， fill: 'tozeroy' 填充， 功率谱密度单位 dB/Hz。FFT 采用自实现的 Cooley-Tukey 算法。
⚠️ 技术注意：PSD 仅显示正频率 (0 ~ fs/2)。对于 cf32_le 复信号， 完整频谱应为 -fs/2 ~ fs/2。当前实现更适合实信号分析， 复信号场景建议扩展为全频段显示。
✅
瀑布图 (Spectrogram) plotSpectrogram() — ~90 行
STFT（NFFT=512, hop=256），heatmap 类型， 深蓝→蓝→黄→红渐变色标( #0f172a → #1e3a5f → #1e66f5 → #3b82f6 → #f59e0b → #ef4444)， 时间/频率轴标注清晰，hover 模板展示精确数值。
✅
标签时间轴 (Annotation Timeline) renderAnnotationTimeline() — 新增 ~80 行
无 annotation 时显示虚线占位框+说明文字；有数据时渲染彩色时间条， 含颜色标识、标签名、样本范围、频率信息(freq_lower_edge / freq_upper_edge)； 可见性过滤（只显示当前窗口内）；点击跳转至起始样本； 状态提示 "X 条可见 · 共 Y 条"。
📌 测试数据包含 3286 条 annotation，均带 core:freq_lower_edge 和 core:freq_upper_edge，可完整验证。

⚠️ 风险与改进建议 7 项

级别 类别 描述
中 算法精度 PSD 单边谱 vs 复信号 — 当前 PSD 只显示 0~fs/2（正频率）。 对于 cf32_le 复基带信号，完整频谱应为 -fs/2 ~ fs/2。 建议为复信号场景增加全频段模式（复信号 FFT 后双边显示）。
中 功能缺失 无 capture 频率切换 — viewer 对所有 capture 段使用同一采样率， 但没有根据当前窗口所在的 capture 段切换中心频率显示。 瀑布图和 PSD 的频率轴标注未考虑 frequency offset。
低 数据验证 无声明 vs 实际样本数校验 — P1 阶段的长度验证功能未集成到 viewer 中。 元数据面板虽展示两者数值，但未高亮或警告差异。
低 性能 全文件内存加载 — loadDataFile() 将整个 .sigmf-data 读入 ArrayBuffer。对于大文件（数 GB），浏览器可能内存不足。 建议使用 Blob.slice() 按需读取范围。
低 可用性 缺少键盘快捷键 — 除 Enter 提交外，无缩放复位(Ctrl+0)、 截图导出、窗口快捷切换等键盘操作。
低 边界条件 Annotation 定位精度 — 标签时间轴使用相对百分比定位， 当 annotation 边界在窗口边缘时可能出现 ±1 样本偏差。
低 向后兼容 依赖 Plotly CDN — 脚本从 CDN 加载 Plotly 2.35.2， 无网络时 viewer 完全无法工作。建议增加本地 fallback 或 Service Worker 缓存。

💡 改进建议（优先级排序）

  • P2.1 — 复信号全频段 PSD：将 Welch PSD 扩展为支持 -fs/2 ~ fs/2 显示（复信号 FFT 后取全部 N 点而非 N/2），瀑布图同理。
  • P2.2 — Capture 频率感知：根据当前窗口所在 capture 段的 core:frequency 调整瀑布图和 PSD 的频率轴标注， 在元数据面板高亮当前 active capture。
  • P2.3 — 数据一致性检查：在元数据面板中增加声明样本数与实际样本数的 差异高亮（红色 / 警告图标），与 P1 的 p1_acceptance.py 逻辑对齐。
  • P2.4 — 大文件支持：使用 Blob.slice() 按窗口范围 读取数据文件片段，避免全文件内存加载。
  • P2.5 — 视图复位按钮：每个图表增加 "复位缩放" 按钮 (double-click 或 toolbar button)，一键恢复初始视图范围。
  • P2.6 — Annotation 颜色一致性：同一 label 的 annotation 使用相同颜色，而非按数组索引取色，提升可读性。
  • P2.7 — 导出截图：增加 Plotly.toImage() 批量导出 功能，方便用户保存分析结果。
