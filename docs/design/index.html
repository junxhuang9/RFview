RFview / SigMF Dataset Reader

面向 RFML 的 SigMF 信号阅读器与数据集管理平台设计

本套 HTML 文档用于方案校准：先定义 SigMF 与 HDF5/RadioML 数据集导入、合规检视、统计分析、时频域可视化、元数据编辑与人工标注的产品架构，再进入程序开发。

总览 系统架构 SigMF 数据模型 数据集管理 文件读取与索引HDF5/RadioML 统计工具 可视化分析 标签与元数据 技术路线 实施路线P0 校准

定位

RFview 是 RFML 工作流前置的数据理解与治理工具。它不先追求训练模型，而是回答“这个 SigMF 数据集是否可信、标签是否完整、波形是否符合预期、统计分布是否适合训练”的问题。

01
检视数据集

校验 .sigmf-meta / .sigmf-data 配对、全局字段、捕获段和标注段是否符合 SigMF 与项目约定。

02
统计数据集

统计采样率、中心频率、调制体制、SNR、样本数量、类别均衡、标签覆盖率与异常片段。

03
观察信号

联动展示 IQ 波形、幅相、功率谱、瀑布图、时频 ROI 和 RFML 样本切片。

04
编辑标注

读取 SigMF annotations，支持修改 meta、手工打标签、版本化审计和导出训练清单。

核心用户流程

导入 SigMF / HDF5 数据集 合规校验与摘要 快速预览波形/频谱 统计分布与异常 修改元数据/标注 导出 RFML 数据清单

MVP 范围

  • 本地文件夹导入：识别 SigMF Recording、Collection、Archive，以及 HDF5/RadioML2018 文件。
  • SigMF schema 校验与项目规则校验。
  • 单记录首屏预览：IQ、幅度、相位、PSD、瀑布图。
  • 数据集统计：文件级、捕获级、标签级和 RFML 切片级。
  • 元数据表单编辑、标注时间轴编辑、保存与撤销。

非目标 / 延后

  • 第一阶段不实现模型训练，只输出可供训练使用的 manifest、切片计划和质量报告。
  • 第一阶段不强依赖云端；远程对象存储和多人协作作为后续扩展。
  • 第一阶段不构建通用解调插件市场，但保留分析插件接口。
