内置视图

视图用途数据来源
IQ 时域查看 I/Q 波形、幅度、相位、异常尖峰和截幅。当前窗口样本 + downsample min/max。
频谱查看当前选区的功率谱密度、峰值、带宽和频率偏移。即时 FFT 或缓存 FFT tile。
瀑布图观察随时间变化的频域能量、突发信号和跳频模式。多分辨率 FFT tile。
星座图辅助调制识别和解调质量评估。插件或核心 DSP 输出的符号流。
协议 / 事件表浏览插件输出的包、帧、同步点、告警和标注。结构化插件结果缓存。

联动交互

  • 在瀑布图框选时间和频率范围后，IQ 和频谱视图同步切换到对应窗口。
  • 在事件表选择一个包后，所有图形视图跳转到该包的时间范围。
  • 时间轴支持“回到文件开始处”快捷操作，满足快速定位到起点的需求。
  • 视图缩放时先显示缓存概要，随后请求更高分辨率 tile 替换。

渲染策略

  • 前端只渲染可视范围内的点、线或纹理 tile，避免 DOM 大量节点。
  • 瀑布图使用 WebGL / WebGPU 纹理流，按 tile 增量上传。
  • 颜色映射、动态范围、窗口函数和 FFT 长度均作为可保存的视图参数。
  • 离线导出可复用缓存数据生成 PNG、CSV 或报告片段。
