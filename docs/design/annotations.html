元数据编辑器

区域能力保护措施
Global 表单编辑 datatype、sample_rate、description、author、license、hardware、recorder、自定义字段。必填字段、枚举值、单位、hash 字段和 sample_rate 改动影响提示。
Capture 表格新增/修改 capture 段，维护 sample_start、frequency、datetime。sample_start 单调校验，频率轴重新计算预览。
Annotation 时间轴新增标签、拖拽边界、编辑频带、修改 label/comment、设置复核状态。越界、重叠、类别体系、最小长度和 split 泄漏提示。
Extension 面板显示 namespace、版本、schema URL，编辑项目字段。未知字段原样保留，保存前做 namespace schema 校验。

人工打标签流程

  1. 在瀑布图或时间轴选择时频 ROI。
  2. 选择标签类别、调制类型、信号源、置信度和备注。
  3. 系统生成或更新 SigMF annotation，并实时校验边界。
  4. 复核者确认后标记 reviewed，并写入审计日志。

保存策略

  • 默认保存为工作区 patch，可预览 diff 后再写回 .sigmf-meta。
  • 写回时保持 JSON 格式稳定，减少无意义 diff。
  • 每次保存记录操作者、时间、变更字段、旧值摘要和新值摘要。
  • 支持导出独立 annotation overlay，便于不改原始 meta 的协作场景。

标签体系

项目可以定义 label taxonomy，例如 modulation、emitter、scenario、snr_bucket、quality_flag。RFview 应提供 taxonomy 管理器，把自由文本标签映射成 RFML 训练可用的稳定类别 ID，并在导出时输出映射表。

风险控制

任何会改变样本解释的字段（例如 datatype、sample_rate、captures frequency）都属于高风险编辑。UI 必须展示影响范围，要求用户确认，并使相关预览、统计和 RFML manifest 缓存失效。
