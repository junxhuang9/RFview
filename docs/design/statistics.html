统计工具帮助判断生成的数据集是否符合预期，并为 RFML 训练前的数据筛选、均衡与异常排查提供依据。

统计类别

类别指标用途
文件/采集统计文件数、总样本、总时长、datatype/dtype、采样率、中心频率、capture 数量、HDF5 frame 数。确认数据规模、采集配置和文件一致性。
信号幅度统计I/Q mean、std、min/max、RMS、PAPR、直流偏置、饱和比例、NaN/Inf。发现剪切、归一化错误、硬件偏置和损坏样本。
频域统计平均 PSD、占用带宽、峰值频点、频谱平坦度、噪声底、带外能量。确认调制信号频带、干扰和采集频率配置。
标签统计类别数量、标签片段数、覆盖率、重叠率、片段长度分布、频带宽度分布。判断 RFML 类别均衡与标注质量。
切片统计窗口数、每类切片数、split 分布、重复片段、边界裁剪比例。评估训练样本数量和 train/val/test 泄漏风险。

异常检测规则

  • 文件大小与 datatype/sample_count 不匹配，或 HDF5 X/Y/Z frame 维度不一致。
  • 样本幅度长期为 0、全常量、严重饱和或 I/Q 通道交换可疑。
  • 标签超出文件范围、频带超出 Nyquist 范围、标签重叠冲突。
  • 某类样本过少、split 中同一 recording 被拆到多个集合导致泄漏。

统计交互

  • 点击统计图上的异常点，联动打开对应样本范围的波形/瀑布图。
  • 统计结果可按 recording、label、capture、split 和自定义字段分组。
  • 每个统计快照保存规则版本和参数，保证报告可复现。

报告输出

质量报告应包含摘要评分、阻塞问题、警告问题、标签覆盖、类别均衡、频段覆盖、代表性截图引用和 RFML 导出建议。报告既可在 UI 查看，也可导出为 HTML/JSON，便于训练流水线消费。
