📋 开发历程时间线

P0 设计校准
产出 13 份 HTML 设计文档，覆盖架构（client-server-SigMF）、数据模型、技术路线（Plotly.js/Python CLI/无 Node）、可视化方案、标注 UX、RFML 导出规范、插件扩展等
P1 核心后端验证
Python 后端 9 模块搭建：SigMF 解析（sigmf.py 218 行）、HDF5/RadioML 加载（hdf5.py 113 行）、采样窗口读取（samples.py 121 行）、CLI inspect 工具、质量问题检测。12 个 pytest 全部通过
P2 可视化 MVP
基于 Plotly.js 实现四图联动：IQ 时域图（scattergl 高性能渲染）、星座图（密度着色）、PSD 频谱（Welch 法 + Hanning 窗）、瀑布图（STFT heatmap）。标签时间轴展示 annotation，视图框选同步
P3 标注与元数据
侧边栏元数据表单（Global/Capture/Annotation CRUD）、浮动编辑窗口、Diff 预览（深色背景逐行对比）、保存/撤销/overlay 下载、自定义 KV。修改追踪标记，diff 屏蔽 computed 字段
P4 RFML 就绪
Taxonomy 管理（RadioML 11 类预设，自动统计分布）、Split 分配（分层随机抽样 + mulberry32 种子 PRNG + Fisher-Yates shuffle）、切片预览（窗口/步长可配，瀑布图叠加矩形）、Manifest 导出（JSONL/CSV, 7+4 字段）、质量门禁（4 项检查阻断导出）
P5 扩展能力
远程数据加载（CORS + 30s 超时 + auto-derive）、多人复核（pending/approved/rejected + reviewer/note/timestamp + 批量复核）、批处理导出（会话级资产列表 + 批量 Manifest + 质量报告）、模型回看对比（预测叠加 + IoU 报告）、统计摘要面板（样本/时长/SNR/覆盖率/复核分布/Top6 标签）
🛡️ 修复复审
Linus 终审 3 项遗留问题全部清零：escHtml() 全字段转义、`??` 修复 0 Hz 丢失、O(n²)→O(1) 颜色缓存优化。未引入新问题

🛡️ 质量保障维度

✅ 安全 — XSS 防护
全用户字段使用 escHtml() 转义，statusBar 用 textContent 替代 innerHTML，事件委托替代内联 onclick
✅ 数据正确性
所有 SigMF 字段使用 ??（nullish coalescing）而非 ||，0 Hz / 0 samples 不再丢失。默认 fallback 值使用 0 而非 81920000
✅ 错误处理
loadAndVisualize/handleFileSelect/handleDataFile 均有完整 try/catch，errorBar 显示错误详情，statusBar 统一状态提示
✅ 性能优化
颜色计算 O(n²)→O(1) Map 缓存（labelColorMap 预计算），切片矩形限制 50 个防性能退化
✅ 可复现性
Split 分配使用 mulberry32 种子 PRNG，Fisher-Yates shuffle，种子可设置（整数）或自动
✅ 测试覆盖
Python pytest 12 个测试全部通过，JS 语法验证通过，P2-P5 验收测试全覆盖
✅ 代码质量
全部代码有中文注释，无死代码，命名规范（camelCase 变量 + kebab-case CSS），事件监听标准化
✅ 离线兜底
Plotly.js CDN 加载失败显示离线提示，用户可下载本地 plotly.min.js 替换 script 标签
