格式字段

✅ 质量门禁（4 项检查）

检查项阈值自动检测
标签覆盖≥ 80% annotation 有 label✅ 实时计算
类别均衡最大/最小类别样本数 ≤ 10✅ 实时计算
数据一致性annotation 范围不超出数据文件✅ 实时计算
Split 无泄漏相同 label 的 annotation 不跨 split✅ 实时计算

每项检查显示 ✅ 通过 或 ⚠️ 未通过 + 详情说明。全部通过后导出按钮激活。

🌐 远程数据加载

控件操作

⚠️ 注意事项

📵 离线使用

Plotly.js 图表库默认从 CDN 加载。无网络时页面显示离线提示。解决方案：

# 1. 下载 plotly.min.js 放到 viewer.html 同级目录 wget https://cdn.plot.ly/plotly-2.35.2.min.js # 2. 编辑 viewer.html，将第 9-10 行替换为： # <script src="plotly.min.js"></script>
🌐 远程加载 — CORS

远程数据加载依赖于目标服务器返回正确的 CORS 头。如果遇到 No 'Access-Control-Allow-Origin' 错误，需要服务器端配置。

🧮 数据类型限制

当前仅支持 cf32_le（32 位复数小端浮点，每样本 8 字节）。如需支持其他类型（ci16_le, rf32_le 等），需扩展 decodeCF32() 函数。

🗄️ 大文件处理

viewer.html 为单文件 4,802 行，所有数据加载到浏览器内存中。建议 .sigmf-data 文件大小不超过浏览器可分配内存（通常 2-4 GB）。对于超大文件，使用 起始样本 和 窗口大小 按需加载片段。

🏗️ 无后端架构

RFview 为纯前端 HTML 应用。所有修改保存在浏览器内存中，保存时通过浏览器下载触发文件下载，不会自动持久化到磁盘。

🌍 浏览器兼容

推荐使用 Chrome/Edge/Safari 最新版本。需要 ES2021+ 支持（?? 运算符、Array.fromAsync 等）。不支持 IE 或非常老旧的浏览器。

🐍 Python CLI 使用说明

Python 后端提供离线分析能力，通过 uv 或 pip 安装后使用。

安装

# 推荐使用 uv（无需 pip） cd RFview/ uv venv source .venv/bin/activate uv sync

CLI 命令

命令功能
python -m rfview.cli inspect <path> [--pretty] [--window-samples N] 检测 SigMF meta 文件或 HDF5/RadioML 文件，输出 JSON 健康报告（含质量门禁结果）
--pretty 格式化 JSON 输出（可读模式）
--window-samples N 设置窗口样本数（默认 4096）
--cache-dir DIR 指定缓存目录

使用示例

# 检查 SigMF 文件 python -m rfview.cli inspect Data/trimmedSamples.sigmf-meta --pretty # 检查 HDF5/RadioML 文件 python -m rfview.cli inspect data.hdf5 --window-samples 8192 # 运行测试 python -m pytest tests/ -v
💡 CLI 返回值

返回码：0 = 通过（门禁通过），1 = 未通过（门禁 fail），2 = 错误（无效命令或路径）

Python 模块 API

模块核心接口

hdf5.pyHDF5Adapter — 加载 HDF5/RadioML 数据集
samples.py窗口读取 IQ 二进制样本
health.pyIssue / HealthReport — 质量问题模型
